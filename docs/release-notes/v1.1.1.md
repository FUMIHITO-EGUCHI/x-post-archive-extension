# v1.1.1

保存済み投稿の画像・動画を、形式の分かるファイル名で保存できるようにしました。

## ユーザーにとって良くなったこと

- 投稿ごとの「保存」ボタンから、保存済みの画像・動画をダウンロードできます。複数画像はまとめて保存でき、引用投稿には別の保存ボタンを表示します。
- ファイル名に投稿者・投稿 ID・連番・拡張子が付きます。形式は保存済みの MIME またはファイルの先頭から判定します。

## 修正内容

- ready メディアを投稿ごとに位置順で保存し、表示用 Blob に保存済み MIME を反映しました (#139)。
- リリース時のバージョン・成果物の確認と CI のテストを強化しました (#135)。
- Chrome Web Store 向けの `webRequest` 権限の説明とストアへのリンクを更新しました (#134)。

## 確認状況

- lint・型チェック・95 テスト・ビルドと content script の検査に成功。
- Chrome 156 で4画像・引用画像・動画の計6件を実保存し、元データとの SHA-256 一致を確認しました。実機確認は AVIF 判定追加前のビルドで行い、AVIF 判定は回帰テストで確認しています。
- 画像の右クリック保存と、最終ビルドの Chrome 実機確認は未実施です。
