# v1.2.0

説明文に頼らず、見れば分かる UI に作り直しました。タグの整理も、その場で名前を変えて統合できるようになりました。

## ユーザーにとって良くなったこと

- **投稿カードがすっきりしました**: 「投稿日時」「保存日時」などのラベルをやめ、置き場所とアイコンで区別します。元投稿を開く・再取得・削除は右上のアイコンボタンにまとめました。引用カードも本体カードと同じ配置になりました。
- **絞り込みの状態がひと目で分かります**: 絞り込みボタンに適用件数のバッジが付き、適用中の条件は × で外せるチップで並びます。除外条件は赤で表示します。件数は、絞り込み中なら `N / M` と表示します。
- **ツールバーのボタンを揃えました**: 検索・絞り込み・タグ・並び順・設定のボタンを同じ大きさと色にしました。アイコンも描き直しています。
- **タグの名前をその場で変えられます**: 設定の「タグを整理」でタグ名を押すと入力欄になります。Enter で保存、Esc で取り消しです。既にある名前にすると、そのタグへの統合を選べます。
- **タグの統合が速くなりました**: 確認画面をやめ、「統合」→「統合を確定」の 2 段階ボタンにしました。旧タグと統合先は入れ替えられます。
- **タグの一覧をキーボードで操作できます**: 矢印キーで行を移動し、Home / End で先頭・末尾へ、F2 で名前の変更を始められます。最後の行から ↓ を押すと続きを読み込みます。
- **X 上の保存ボタンが X の操作列に並びます**: 未保存・保存中・保存済（緑の✓）・失敗（赤の！、押すと再試行）をアイコンで出し分けます。連投でないページでは連投保存のボタンを出しません。
- **X の表示言語（日本語 / 英語）に合わせて文言が切り替わります**: 保存ボタン・連投保存・一括取り込みの表示が対象です。言語を変えると開いているページの表示もすぐ切り替わります。
- **一覧の「さらに表示」が縮まなくなりました**: 続きを読み込んだあとで行を選ぶと、表示が最初の件数に戻ってしまう不具合を直しました。

## 修正内容

- viewer の投稿カード・ツールバー・モーダル・設定を、説明文の代わりに配置・アイコン・状態表示で伝える形に作り直しました (#146)。
- X 上の保存ボタン・連投保存・一括取り込みの表示を作り直し、日本語と英語の文言をそろえました (#146)。
- アイコンを描き直し、viewer と X 上の保存ボタンで同じ形にそろえました (#147)。
- タグ整理を、その場での名前変更・2 段階の統合・キーボード操作に対応させました。名前の変更や統合のあとも一覧が消えず、最新の内容を表示します (#147)。
- 一覧の「さらに表示」が、行の選択を変えると最初の件数に戻る不具合を直しました (#147)。

## 確認状況

- lint・型チェック・125 テスト・ビルドと content script の検査に成功。
- viewer は Playwright の Chromium（デモアーカイブ、ja / en）と実データの Chrome で確認しました。ツールバーの寸法はダーク・ライトの両方、タグ整理の一覧のキー操作、引用カードの表示を見ています。コンソールエラーはありません。
- X 上の保存ボタンは、ログイン済みの Chrome で保存中から保存済への遷移と表示言語の切り替えを確認しました。
- 未確認: 描き直した保存アイコンの X 上での見た目、連投ページでの連投保存ボタン、実際の X 上での一括取り込みオーバーレイ、実データでのタグの名前変更・統合の実行。
